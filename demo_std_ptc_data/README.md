# Standard procedure sample data

`standard_procedures.json` contains 10 short, versioned illustrative condition records. Each record has a stable ID, aliases for semantic retrieval, structured sections, source URL, and review date.

The text is intentionally concise for a demo. It is not a clinical protocol or a substitute for professional guidance. Before real use, a qualified clinical content owner must review and approve each canonical record, define its population and care-setting applicability, and establish a scheduled update process. Preserve the exact stored text at retrieval time to meet the deterministic wording requirement.
